# Kafka Clsuter Infrastructure Setup

##Overview
This project contains AWS infrastructure setup for kafka cluster implementation using infrastructure as code

This project includes:
- VPC Creation
- Subnet
- Internet Gateway
- Route Tables
- Security Groups
- EC2 Instances
- Kafka Installation and Configuration
- Automatic AWS Secrets Manager Integration

---

Changes Made
- Updated existing cluster infrastructure
- Added automatic AWS Secrets Manager secret creation and usage
- Improved infrastructure security by converting resources from public to private architecture
- Reorganized file structure for better understanding and maintainability
